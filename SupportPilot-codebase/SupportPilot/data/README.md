# Dataset

Place the supplied CSV in this folder, or set `SUPPORTPILOT_DATA_PATH` in `.env` to its location.

Expected columns in the supplied dataset include `subject`, `body`, `answer`, `type`, `queue`, `priority`, `language`, and `tag_1` through `tag_8`.

The dataset itself is not bundled in this repository ZIP. Do not commit customer or otherwise sensitive ticket data to version control.
