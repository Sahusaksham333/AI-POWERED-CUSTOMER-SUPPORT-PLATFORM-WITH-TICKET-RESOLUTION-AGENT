# Knowledge base content

Place **approved, current, organization-specific** troubleshooting guides here as `.md`, `.txt`, `.pdf`, or `.docx` files and index them with:

```powershell
python scripts/index_knowledge_base.py --reset
```

The example below is only a scaffold to test ingestion. It is not an authoritative IT policy or a verified solution for your organization. Replace it with approved material before relying on generated responses.
