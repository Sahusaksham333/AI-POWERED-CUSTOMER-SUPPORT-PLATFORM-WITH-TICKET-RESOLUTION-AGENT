# SAMPLE ONLY — VPN connection troubleshooting

This sample document is for testing the ingestion pipeline only. Confirm all steps against the VPN vendor's documentation and your organisation's security policies before use.

## Information to collect
- Operating system and VPN client version.
- Exact error message and approximate time of failure.
- Whether the user can access ordinary internet resources.
- Whether other users are affected.

## Safe preliminary checks
1. Confirm the device has a working internet connection.
2. Record the exact VPN error before changing configuration.
3. Check the organisation's approved service-status page, if one exists.
4. Avoid asking users to disclose passwords, MFA codes, private keys, or session tokens.
5. Escalate repeated authentication failures, certificate warnings, or suspected compromise to the authorised IT team.

Do not disable endpoint protection, bypass certificate validation, or share VPN credentials as a troubleshooting shortcut.
